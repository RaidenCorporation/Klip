**Klip** is a fun, antistress and lightweight game. Feeling stressed? Play Klip and start smashing rocks to make shards to farm coins! 

---

Klip is a game where you smash rocks into each other to create **shards**, which are basically your coins and you use them to buy new **skins**. Each skin gives a bigger payout than the other, but they get more expensive as you go. 

_New skins get added almost every update, there is never an end for new skins._

---

# 🖥️ Platform Availability
Klip is only available as an APK for Android.

---

# 📩 How To Download
1. Look for the latest APK from the latest release on the [Releases](https://github.com/RaidenCorporation/Klip/releases) tab.
2. Scroll down on the latest release to see “Assets”.
3. In the Assets section, look for **app-release.apk** and click it.
4. Wait for it to install.
5. Go to your regular Files app.
6. Look for app-release.apk.
7. Once you found the file, press the 3 dots ⋮ or hold the file and press "Install".
8. It will be installed to your device. Enjoy!
